# Astra RoboCasa Episode Replay

A replay of a successful GPT-6-Astra / xhigh BreadSelection episode (seed 4), recorded with HarnessVLA / RPent on RoboCasa365.

The viewer includes the original 41.2-second simulation video and all 11 recorded tool calls, with arguments, results, camera snapshots, and action-to-video alignment. The full run took 348.1 seconds; the video omits inference and waiting time.

Local machine paths in tool records are replaced with relative labels. This is an episode visualization, not a benchmark aggregate.

Built on [RPent](https://github.com/RLinf/RPent), RoboCasa, and RLDX-1.
